# C Programs

A collection of programs written in the C programming language.

This repository contains my C programming projects, experiments, and exercises as I learn the language.

## Requirements

- GCC
- Linux or another Unix-like operating system
- Terminal

Install GCC on Arch Linux:

```bash
sudo pacman -S gcc
```

## Compilation

Compile a C program:

```bash
gcc main.c -o program
```

Run it:

```bash
./program
```

For debugging:

```bash
gcc -Wall -Wextra -g main.c -o program
```
